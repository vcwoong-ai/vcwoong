- 정확한 배포 SHA, 도메인 alias, READY 여부와 실제 앱 인증 성공을 따로 기록한다.

## CRON_SECRET 안내

사용자가 Vercel의 기존 프로젝트 환경변수에서 CRON_SECRET의 Sensitive 지원 여부를 확인한다. 값을 채팅에 붙여넣지 않는다.
Sensitive 전환·값 교체·재배포는 본 작업에서 실행하지 않았다. 값을 교체할 경우 cron 인증을 사용하는 코드와 배포 환경의 일치를 함께 확인해야 한다.
