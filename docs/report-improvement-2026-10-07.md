# 보고서 읽기와 출력 개선

투자심사역이 결론과 남은 쟁점을 먼저 파악하도록 보고서를 투자 요약, 핵심 수치, 전체 판단 근거와 상세 분석 부록 순서로 구성했다. 이번 변경은 보고서 표현과 출력의 첫 단계다. 회의 기록을 판단 근거에 연결하거나 계약과 투자 집행을 관리하는 기능은 포함하지 않는다.

## 구현 범위

- 보고서 기본 화면은 읽기이며 기존 편집, 근거 검토, 질문과 품질 도구는 작성·검증 화면에서 제공한다. 편집과 저장·재생성 중에는 읽기 화면 전환을 막는다.
- 요약은 투자 논지, 투자 조건, 주요 투자 근거, 반대 근거와 확인할 자료를 보여준다. 주요 항목은 각각 3건이며 전체 항목과 상세 설명은 판단 근거에 보존한다.
- 같은 서버 조립 결과를 읽기 화면, 인쇄 화면, Word와 표준 PPTX가 사용한다. 요약 상태는 자동 검토 결과이며 심사역 최종 의견이나 투자 승인이 아니다. 평가 근거가 없거나 일관성 검사를 통과하지 못하면 판단 준비 중으로 표시한다.
- 차트는 출처가 있는 매출·영업이익·순이익의 연도별 수치에 한정한다. 기간, 실적과 전망, 단위와 부호를 원문 발췌에서도 확인한다. 불명확한 비교나 같은 기간의 값이 상충하면 차트를 생략한다. 단위를 억원으로 맞추되 음수와 0을 보존하고 원본 문서 이름과 위치를 함께 제공한다.
- 화면과 인쇄는 막대 차트와 출처 표를 제공한다. 표준 PPTX는 편집 가능한 차트와 출처 표를 포함한다. 표준 Word는 수치를 실제 표로 제공하며 차트 그림을 추가하지 않았다.
- 긴 PPTX 본문과 표는 계속 슬라이드로 나눈다. 서로 다른 지표나 단위를 본문 숫자만으로 막대 차트에 섞던 방식과 행·문장 수에 따른 삭제를 제거했다.
- 회사 양식 PPTX는 별도 선택 항목이다. 양식 보존 경로에는 요약이 포함되지 않을 수 있다. Word의 기존 회사 양식 경로는 유지한다.

## 검증과 운영 상태

합성 자료로 실제 근거 추적부터 차트 조립, 요약의 미완료 상태, 전체 부록 보존, React 정적 렌더링과 Word·PPTX 패키지 내용을 검사했다. 기존 보고서 편집 충돌 보호, 출력 상태 변경과 비공개 응답 검사도 통과했다. 전체 회귀 스크립트 128개, TypeScript 두 설정, 집중 린트와 프로덕션 빌드가 통과했다. 전체 검사에서 발견한 SVG 제목 경고를 수정하고 관련 검사를 다시 통과했다. 로컬 키 3개의 공개 소스 노출 검사에서 노출된 파일은 없었다.

localhost 브라우저 접근 제한이 유지되어 실제 반응형 화면, 인쇄 페이지 나눔과 PowerPoint에서의 시각적 배치는 아직 확인하지 않았다. 요약이 반드시 물리적인 한 페이지에 들어간다는 보장은 하지 않는다. 실제 고객 자료의 원문 구조에 따라 조건을 충족하는 차트가 없을 수 있다.

배포, Git 커밋·푸시와 기존 데이터베이스 변경은 수행하지 않는다. 보존된 vcwoong 체크아웃과 로컬 비밀정보를 변경하지 않는다.

## 이어서 개발할 범위

첫 번째 범위의 VC 보고서 연결은 [회의록과 리서치 연결 기록](decision-context-2026-10-07.md)에 구현·검증 범위를 기록했다. PE 반영과 자료 요청의 업무 관리까지 완료한 것은 아니다.

1. 리서치 결과와 승인된 회의록의 주장·질문을 회사별 근거에 연결하고, 기존 자료와 다른 내용을 상충 항목으로 표시한다.
2. 심사역의 투자 논지, 반대 논지, 조건부 진행과 보류 사유를 기록하고 자동 검토와 구분한다.
3. 추가 자료 요청과 확인 상태를 실사 항목에 연결한다. 계약 조건, 승인과 투자 집행은 별도의 단계 및 권한으로 관리한다.

회의록을 요약하는 것만으로 투자 판단 근거를 확정하지 않는다. 발언 출처, 원문 위치, 사용자 승인과 자료에 의한 확인 상태를 함께 연결해야 한다.
