# 회의록과 리서치의 투자 판단 근거 연결

VC 보고서에서 승인된 회사 미팅 기록과 저장된 딥다이브 리서치를 함께 검토할 수 있도록 연결했다. 회사 발언, 사용자 확인 메모, 외부 리서치의 AI 대조 결과를 구분하며 기존 투자 점수·자동 권고·승인 본문을 변경하지 않는다. PE 보고서 반영, 추가 자료 요청의 담당자·기한 관리와 심사역의 최종 판단 저장은 후속 범위다.

## 보고서에서 확인하는 흐름

읽기 화면의 미팅·리서치 근거에는 확정 회의록과 주장, 질문·자료 요청의 수를 표시한다. 대조할 수치가 있으면 주요 3건을 먼저 보여주고 전체 항목은 판단 근거에 보존한다. 회의 이름을 선택하면 같은 딜의 해당 기록을 열며 보고서에서 참조한 버전과 현재 버전·확정 상태가 다르면 재검토 안내를 표시한다. 회의록 변경 뒤에는 보고서의 근거 새로고침으로 최신 상태를 확인한다.

회의록의 주장에는 검토 확정 버전, 일시, 녹음 시간 구간, 해당 구간의 전사와 확인 메모를 연결한다. 시간 구간에서 전사를 찾을 수 없으면 원본 재확인을 안내한다. 회의록의 사용자 확인 상태를 독립 사실 검증으로 승격하지 않는다.

자동 수치 대조는 연도, 매출·영업이익·순이익, 원화 단위, 실적 또는 전망이 명시된 문장에 한정한다. 회의록의 숫자와 같은 기재 값이 전사 구간에서도 확인되어야 한다. 같은 회계 범위의 문서 수치와 비교하되 기간·지표·실적/전망이 다르면 충돌로 표시하지 않는다. 원화 단위를 맞추고 음수와 0을 보존한다. 상대 연도, 분기·월간, 범위·대략값, 외화와 단위가 불명확한 표기는 사람이 대조한다. 다른 기재 값을 발견해도 어느 쪽이 맞는지 확정하지 않는다.

리서치는 현재 보고서에 저장된 딥다이브 결과를 재사용한다. 원문 링크와 대조 시점을 제공하며 현재 보고서에서 같은 주장을 찾을 수 없거나 이후 보고서·자료가 바뀌면 재확인을 안내한다. 출처가 없거나 데모 결과이면 지지·불일치 판정을 확정적으로 제시하지 않는다. 재파싱 이력을 완전히 추적하는 리서치 입력 해시는 아직 없으므로 문서 재파싱 뒤의 모든 변경을 자동 감지한다고 주장하지 않는다.

## 조회와 출력의 일관성

상세 읽기 API와 Word·표준 PPTX·인쇄는 같은 조립 함수를 사용한다. 참조가 추가되어도 원래 보고서 본문과 승인 상태를 자동으로 덮어쓰지 않는다. 회의록 수정으로 초안이 되거나 삭제되면 현재 참조에서 제외한다. 이미 내려받은 파일은 해당 시점의 참조를 포함한 별도 사본이다.

출력 중 승인 회의록이나 리서치 결과가 바뀌면 기존 출력 스냅샷으로 현재 보고서를 EXPORTED 처리하지 않도록 입력 버전 검사를 확장했다. 팀·딜 읽기 범위에서만 조회하며 다른 딜의 회의, 삭제된 기록, 원본 저장 주소와 참가자 목록은 이 참조에 넣지 않는다. 딜 목록 배치 조회는 전체 전사와 리서치를 가져오지 않는다.

회의 기능이 꺼져 있으면 기존 DB에 새 Meeting 테이블이 없어도 보고서를 조회할 수 있도록 해당 관계를 쿼리하지 않는다. 기능과 운영 DB는 활성화하지 않았으며 추가 비밀키도 필요하지 않았다. 저장된 기록의 조회만 연결했으며 실제 음성 전사·외부 검색·AI 호출을 새로 실행하지 않았다.

## 검증

새 순수 함수 검사에서는 기간·단위·부호·회계 범위와 전사 대조, 초안·삭제·잘못된 기록 제외, 오래된 리서치와 안전하지 않은 URL, 원래 판단·문서 검증 상태 보존, Word·PPTX의 인용 보존을 확인했다. 실제 상세 API를 격리된 메모리 포트로 실행해 비로그인·다른 사용자 거절과 비공개 응답을 검사했다. 인용 시간과 관계없는 전사 전문은 응답에 포함하지 않는다.

격리 SQLite에서 실제 승인 회의의 관계 조회, 다른 소유자의 접근 거절과 수정 후 참조 제외를 검사했다. 기존 출력 상태 검사는 회의·리서치 입력 변경 시 이전 스냅샷의 완료 처리를 차단함을 확인한다. 전체 회귀 검사 129개, 집중 린트와 프로덕션 빌드는 통과했다. 빌드가 생성 파일을 갱신하는 동안 병행한 TypeScript 검사는 파일 경합으로 실패했으며 빌드 후 두 설정을 다시 검사해 통과했다.

브라우저 접근 제한이 유지되어 실제 링크 이동, 키보드·반응형 화면과 인쇄 배치는 미검증이다. 고객 음성·실제 외부 공급자·운영 PostgreSQL의 이 경로는 검사하지 않았다. 기존 데이터베이스, 비밀정보와 보존 체크아웃을 유지했고 커밋·푸시·배포를 수행하지 않았다.
