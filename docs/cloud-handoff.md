# DealMind 컴퓨터·클라우드 작업 이전

## 기준

사용자가 기존 공개 저장소 `vcwoong-ai/vcwoong` 사용을 선택했다. 이전 브랜치는 `codex/cloud-migration-20261006`이다. 기존 컴퓨터의 소스와 Git 이력을 로컬 백업으로 보존하고 새 컴퓨터/클라우드는 이 브랜치를 기준으로 시작한다. main 병합·운영 배포·키/권한/운영 데이터 변경은 이전 작업에 포함하지 않는다.

로컬 백업은 `.dealmind-backups/` 안에 있다. source-working-tree.zip은 Git 추적 파일과 무시되지 않은 작업 파일, history.bundle은 Git 이력, manifest.json은 소스 복원 무결성 확인용이다. 환경 파일·업로드·DB·런타임 메모리 등 Git 무시 파일은 원래 컴퓨터에 그대로 보관되며 공개 저장소로 옮기지 않는다. 백업만으로 이 데이터까지 복원된다고 주장하지 않는다.

## 새 컴퓨터

```sh
git clone --branch codex/cloud-migration-20261006 https://github.com/vcwoong-ai/vcwoong.git Dealmind
cd Dealmind
```

Codex에서 이 폴더를 프로젝트로 등록한다. 가입한 서비스 설정은 별도 안전한 경로로 연결하며 기존 `.env`를 공개 저장소에 올리지 않는다. 클론 뒤 아직 GitHub에 반영되지 않은 다른 컴퓨터의 변경을 덮어쓰지 않는다.

## 노트북 전원을 꺼도 작업하려면

Codex Cloud에서 GitHub 저장소를 연결한 환경을 만들고 **이전 브랜치**를 선택하여 클라우드 작업을 시작한다. 기존 로컬 자동화를 만들었다는 사실만으로 클라우드 실행이 보장되지 않는다. 클라우드 환경 게시·작업 시작·실행 결과를 실제로 확인한 뒤 전환 완료로 기록한다. 반복 실행이 필요하면 클라우드 실행 주체·스케줄·비용/권한·종료 조건을 별도로 연결한다.

계정별 환경 생성/접근이 필요하면 사용자가 해당 계정으로 승인한다. 운영 자격정보는 클라우드 연결 목록에서 필요한 것만 별도로 관리한다. 실제 유료 AI·결제·운영 데이터 쓰기/삭제·배포를 자동 실행하지 않는다.

## 기존 Codespaces 설정의 범위

`.devcontainer/devcontainer.json`과 `setup.mjs`가 있다. 이 설정은 합성 디자인 검토용 SQLite·로컬 스토리지와 seed를 사용한다. 기존 환경 파일·외부 DATABASE_URL을 거절하며 초기화 전에 보존한다. 작은 PE 업로드의 PostgreSQL 예약/CAS 및 결제·팀·보고서 관련 PostgreSQL 검증 전체를 이 SQLite 환경에서 통과했다고 주장하지 않는다. 전체 검증 환경은 별도의 격리 PostgreSQL이 필요하다.

Codespaces는 원격 개발 환경이고 Codex Cloud는 클라우드 에이전트 작업 환경이다. Codespace가 생성됐다는 사실만으로 무인 작업이나 무제한 지속 실행이 보장되지 않는다.

## 다음 제품 작업

목표는 실제 고객의 구매와 업무 완료다. 모바일은 주요 행동과 상태를 우선하고 상세 근거/설정은 필요할 때 펼친다. 실제 결제 활성화는 공급자 계약·정책·원장 이전·검증 조건이 남아 있으므로 버튼만 켜서 완료로 처리하지 않는다. `external-service-connections.md`와 `autonomous-progress.md`를 먼저 읽고 이미 완료한 일을 반복하지 않는다.

확정 원본의 PE 재추출은 로컬 PG·모바일 TXT·합성 DOCX/PPTX/XLSX/PDF 실제 파서에서 확인했다. 실서비스 저장 정책/문서 품질·파서 자원 격리·배포 PDF 동적 자산 추적은 별도 미검증 범위다. 형식별 테스트는 메모리 repository/storage ports이며 실제 클라우드 원본 읽기의 증거는 아니다.

## 전환 완료 확인

- 이전 브랜치의 커밋과 주요 소스가 원격에서 확인된다.
- 새 컴퓨터에 같은 커밋을 내려받고 프로젝트를 연다.
- 클라우드 환경이 게시되고 해당 브랜치의 작업이 실제로 실행된다.
- 새 컴퓨터를 꺼도 해당 클라우드 작업이 이어지는 것을 확인한다.
- 기존 컴퓨터의 백업은 보관하고 삭제하지 않는다.

준비와 실제 연결/실행 확인을 구분한다. 이 문서 생성만으로 이전 완료를 선언하지 않는다.
