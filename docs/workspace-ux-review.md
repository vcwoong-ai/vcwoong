# 내부 업무 화면 개선

## 변경

- 딜소싱·딜 관리·보고서에 상태별 건수 그래프. 현재 로드된 목록의 범위와 분모를 표시하며 전환율이나 투자 점수로 표현하지 않는다.
- 보고서 목록의 전체 건수는 서버 count를 사용한다.
- 보고서 본문에서 연도 열과 단위가 명시된 표의 최대 4개 행을 그래프로 표시한다. 원본 표는 유지하며 누락·불확실 표기·잘못된 숫자는 null로 남긴다. 엔진 계산이나 자동 판단을 추가하지 않는다.
- 근거 API의 분류 건수와 수치·출처 비교표, 원문 발췌 펼치기. 추출 주장이 없는 상태를 검증 완료로 표시하지 않는다.
- 보고서 목차, 본문·근거·IC 질문 바로가기, 생성 3단계 안내, 모바일 줄바꿈.
- 근거가 모이는 D 형태의 브랜드 심볼과 파비콘, 접을 수 있는 섹터 도구 안내.
- 로그인 실패/응답 없음의 잘못된 이동 방지와 자동완성 필드 설정.
- 설정의 저장소 라벨이 기존 Blob 자동 선택과 일치하도록 수정.

## 검증

- main a5796bb 기준 독립 작업 공간, 별도 SQLite DB와 localhost:3003.
- test:all PASS (기존 VC/PE/보안 회귀 + 새 표 시리즈 테스트).
- test:login-email-e2e PASS: 기존 대소문자 계정, 신규 가입, 충돌 거부, 동시 가입, 비밀번호, 계정 ID/역할 보존 및 desktop/mobile 로그인.
- test:site-review-e2e PASS: 1440/390 공개·인증 화면과 PE 탭/키보드 75항목. 보고서 목차·표 그래프·근거 비교표 표시 및 overflow도 추가 검증.
- tsc --noEmit, lint, build, diff --check PASS.
- 첫 E2E는 편집 중 JSX 오류로 실패. 수정 후 전체 재실행 PASS. 테스트 삭제/약화 없음.
- 신규 외부 데이터 호출, AI 생성, 실결제, 운영 배포는 검증 범위에 포함되지 않는다. 그래프는 앱 읽기 화면에 추가되며 DOCX/PPTX/PDF 내보내기 변경은 포함하지 않는다.

운영 계정·연동·보안 점검 상세는 개인정보와 배포 설정을 포함하므로 공개 저장소에 게시하지 않는다.
