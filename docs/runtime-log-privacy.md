# DB·DART 로그 보호

공통 `src/lib/prisma.ts`의 Prisma 자동 query/error/warn 출력을 개발·테스트·운영 모두 비활성화한다. 쿼리와 엔진 예외에는 문서 텍스트·재무 입력·인증 관련 값이 포함될 수 있으므로 자동 로그에 보내지 않는다. 기존 singleton/cache 동작과 DB 요청·예외 전달은 유지한다.

이미 생성된 개발 서버의 캐시 인스턴스는 이전 로그 설정을 유지할 수 있다. 변경 적용 후 서버 프로세스를 다시 시작해야 한다. 코드 변경은 현재 로컬이며 운영 배포되지 않았다.

PE 딜 수정·DART 가져오기 저장 오류와 공통 DART 조회 오류는 원본 예외 대신 고정 이벤트 식별자를 기록한다. 실패 응답·화면 안내에도 이번 수정 동작의 서버 오류 원문을 포함하지 않는다. 상세 원문 진단을 잃는 대신 안전한 오류 위치와 테스트 재현 조건을 기록한다.

이 변경은 모든 애플리케이션의 수동 console 로그나 외부 공급자 수집 정책까지 검사했다는 뜻은 아니다. 실제 고객 자료 사용 전 다른 명시적 로그·모니터링 전달·보관 정책도 검토해야 한다. 기존 로그 삭제·보관 설정 변경·운영 권한 변경은 수행하지 않았다.

검증: `test:prisma-log-policy`는 실제 singleton 소스를 VM에서 실행해 각 NODE_ENV의 새 생성 옵션 log[]와 캐시 재사용을 확인한다. 실제 DB/자격정보는 사용하지 않는다. PE 콜백 VM/격리 브라우저의 합성 private marker로 오류 원문이 화면에 나타나지 않는지 확인한다. DART 장애는 응답 주입이며 실제 외부 서비스 장애·API 연결 검증을 대체하지 않는다.
