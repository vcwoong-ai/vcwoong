# 내부 심사역 인터뷰 질문지

대상: VC/PE 업무를 실제 수행하는 내부 심사역 3–5명. 가능하면 양쪽 트랙을 포함한다. 1인 25–30분.
현재 인터뷰를 수행한 것은 아니다. 관찰 결과나 사용성 개선 효과는 아직 없다.

## 진행과 기록

1. 목적과 자발적 참여를 설명한다. 제품 평가가 개인의 업무 평가가 아님을 안내한다.
2. 최근 작성한 보고서의 작업 과정을 회상하도록 한다. 실제 자료를 볼 때 회사/고객 정보는 가린다. 새로운 자료를 외부에 업로드하지 않는다.
3. 격리 fixture 화면에서 첫 딜 안내와 근거/상충 패널을 관찰한다. 결제와 AI 생성은 실행하지 않는다. 막히면 바로 설명하지 말고 어떤 행동을 시도하는지 기록한다.
4. 마무리에서 해석이 맞는지 확인한다. 기능을 소개하며 답을 유도하지 않는다.

기본은 익명 메모이며 녹음하지 않는다. 꼭 녹음해야 하면 별도 동의를 먼저 받고 보관 범위를 정한다.
메모는 P01 등 임의 번호로 기록하고 이름/회사명/딜 수치/원문은 남기지 않는다. 원 메모는 14일, 비식별 종합 결과는 90일 후 담당자가 삭제한다. 인용은 동의와 비식별 처리 후 사용한다.

## 관찰형 질문

- 가장 최근 보고서 하나를 떠올려 주세요. 시작부터 제출까지 어떤 순서로 작업했습니까?
- 보고서 작성에서 가장 오래 걸린 단계는 무엇이었습니까? 그때 어떤 자료나 사람이 필요했습니까?
- 보고서에 넣은 수치 하나의 근거를 어떻게 확인했습니까? 가능하면 확인 경로를 보여 주세요.
- 같은 항목의 수치가 자료마다 달랐던 사례가 있습니까? 당시 무엇을 비교하고 어떻게 기록했습니까?
- 확인하지 못한 정보가 있었을 때 보고서나 회의 자료에 어떻게 남겼습니까?
- 검토 중 추가 질문을 정하고 동료에게 전달한 과정을 설명해 주세요.
- 지금 빈 화면을 보시면 무엇부터 하시겠습니까? 그렇게 생각한 화면 요소를 짚어 주세요.
- 예시 회사의 첫 딜을 만들어 주세요. 다음에 무엇을 입력하거나 확인하시겠습니까?
- 이 근거 화면에서 읽은 정보를 설명해 주세요. 원자료를 더 확인하려면 어떤 행동을 하시겠습니까?
- 이 상충 표시를 보고 어떤 정보를 알 수 있습니까? 알 수 없는 것은 무엇입니까? 실제 검토였다면 다음에 무엇을 하시겠습니까?
- 평소 수치가 다른 상황을 처리하던 과정과 이 화면을 사용하는 과정에는 어떤 차이가 있습니까?
- 이 화면에서 검토 준비 상태와 투자 승인 여부를 각각 어떻게 이해했습니까?
- 업무에 돌아간다면 지금까지 본 화면 중 어떤 것을 언제 사용하겠습니까? 사용하지 않을 화면도 설명해 주세요.

중립 후속 질문: “그때 무엇을 했습니까?”, “어디에서 그렇게 읽었습니까?”, “다음 행동을 보여 주세요.”
“도움 되죠?”, “쉽죠?”, “돈을 내고 싶죠?” 같은 유도 질문과 기능을 칭찬하는 설명은 하지 않는다.

## 기록 양식

| 과제/질문 | 관찰한 행동·발언 | 막힌 위치/소요 시간 | 진행자 개입 | 해석/후속 확인 |
|---|---|---|---|---|
| 첫 딜 생성 / 근거 확인 / 상충 검토 | 실제 기록 | 관찰값 또는 회상 추정이라고 구분 | 설명/힌트 여부 | 관찰 사실과 해석을 분리 |

종합 시 반복 관찰, 단일 사례, 요청사항, 미확인 가설을 분리한다. 3–5명의 의견을 전체 고객의 선호나 구매 의사로 일반화하지 않는다. 개인정보가 담긴 화면 캡처를 보고서에 첨부하지 않는다.
