# 지분플랜 (EquityPlan) — 투자유치 지분 시뮬레이터

창업자와 투자자가 **라운드마다 지분이 어떻게 바뀌는지**, **엑싯 때 누가 얼마를 받는지**를
한국 투자계약 구조 그대로 계산하는 오프라인 단일 파일 프로그램.
1회 결제, 구독 없음, 서버 없음, AI 없음.

> DealMind 본 제품과는 별개다. `src/`(Next.js 앱)와 의존성·빌드·배포를 전혀 공유하지 않는다.

---

## 1. 왜 이걸 골랐나 (냉정한 판단)

### 회의록 프로그램(예시 아이디어)을 버린 이유

| 기준 | 회의록(AI 없음) | 판단 |
|---|---|---|
| 핵심 가치 | 회의록의 가치는 **녹음 → 글자 변환(STT)**. STT 자체가 AI. AI를 빼면 "양식 있는 메모장"이 남음 | 돈 낼 이유가 약함 |
| 경쟁 | 클로바노트·다글로 등 무료/저가 STT, 노션·한글 템플릿 무료 | 가격 경쟁 불가 |
| 차별화 | 우리에게 회의록 도메인 우위 없음 | 없음 |

### 고른 기준

1. **하루 안에 완성** — 서버·DB·로그인·AI 없이 끝나야 함
2. **보자마자 사고 싶음** — "내 돈"이 걸린 숫자를 바로 보여줘야 함
3. **운영 시간 거의 0** — 결제·파일 전달을 플랫폼이 자동 처리, 서버 비용 0
4. **우리만의 우위** — VC 도메인(투심·RCPS·리픽싱)을 이미 알고 있음

### 후보 비교

| 후보 | 하루 완성 | 구매욕 | 자동 수익 | 도메인 우위 | 결론 |
|---|---|---|---|---|---|
| AI 없는 회의록 | O | 낮음 | O | 없음 | 탈락 |
| 노션/엑셀 템플릿 판매 | O | 중간 | O | 약함 | 단가 낮고 복제 쉬움 |
| 마이크로 SaaS(구독) | X (인증·결제·서버) | - | 운영 부담 | - | 하루 불가 |
| **캡테이블·라운드 시뮬레이터** | O | **높음** (투자 직전 창업자) | O | **강함** | **채택** |

**구매 순간이 명확하다.** 텀시트를 받은 창업자는 "참가적 1.5x, 리픽싱 70%"가 내 몫을 얼마나 줄이는지
그날 알아야 한다. 엑셀은 SAFE 전환·옵션풀 확대가 서로 맞물려 수식이 순환하고, 해외 SaaS는 영문·구독·미국 계약 기준이다.
캡테이블은 민감 자료라 "서버 없음, 내 PC 밖으로 안 나감"이 그대로 판매 포인트가 된다.

### 수익에 대한 냉정한 전망

- 이건 **월 수천만 원짜리 사업이 아니다.** 시장(한국 연간 초기 투자 유치 스타트업 수천 곳 + 예비 창업자)은 작고,
  검색 유입이 쌓이기까지 수 주~수개월 걸린다.
- 현실적인 시나리오: 월 방문 1,000~3,000명, 구매 전환 0.5~1.5% → **월 5~45건, 25만~220만 원**.
  액셀러레이터 팀 라이선스(₩190,000)가 몇 건 붙으면 그 위.
- 대신 **운영비 0원, 유지 시간 월 1시간 이하**, DealMind 리드(창업자·VC 연락처) 확보 채널로도 쓸 수 있다.
- 가장 큰 리스크는 **유입**이다. 아래 4장의 배포 채널을 첫 2주에 한 번씩 돌리는 것이 매출의 대부분을 결정한다.

## 2. 무엇이 만들어졌나

| 파일 | 용도 | 공개 여부 |
|---|---|---|
| `dist/site/index.html` | 판매 랜딩 페이지 (예시 계산 수치는 빌드 때 엔진으로 실제 계산) | 공개 배포 |
| `dist/site/demo.html` | 무료 체험판 (계산 전부 가능, 저장·내보내기·4번째 라운드 잠금) | 공개 배포 |
| `dist/release/EquityPlan.html` | **판매용 정식판** 단일 파일 (더블클릭 실행, 오프라인) | **공개 배포 금지** — 결제 플랫폼에만 업로드 |

### 기능

- 가격 라운드: 프리머니·공동투자자 → 주당 가격(원 단위), 신주(주 단위 내림), 실제 납입액, 포스트머니
- SAFE(조건부지분인수계약): 밸류캡·할인율 → 다음 가격 라운드에서 유리한 가격으로 전환
- 옵션풀 확대: 투자 후 목표 %를 프리머니에 포함해 역산 (SAFE 전환과 동시에 고정점 반복으로 풂)
- RCPS 청산우선권: 배수, 참가적/비참가적, 참가 상한, 후속 라운드 선순위/동순위
  - 비참가적·상한 있는 참가적 우선주는 **우선권 행사 vs 보통주 전환 중 유리한 쪽을 자동 판정**
- 리픽싱: 가중평균(broad-based)·풀 래칫, 최초 전환가 대비 하한(%)
- 라운드별 지분 변화 차트, 단계별 캡테이블(주주별 합계 + 주식 종류별 원장), 엑싯 금액별 분배 곡선
- 정식판: 자동 저장(브라우저), 시나리오 파일 저장/불러오기, 엑셀용 CSV(BOM 포함), PDF 보고서(인쇄 CSS)

### 알려진 단순화 (FAQ·면책 문구에 반영됨)

- 스톡옵션은 행사가 차감 전 금액으로 분배 (행사가 필드 없음)
- 리픽싱은 이번 라운드 신규 투자자도 함께 희석되는 것으로 계산 (실무에서 협상으로 달라질 수 있음)
- SAFE 밸류캡은 라운드 프리머니와 같은 기준(완전희석, 확대된 옵션풀 포함)으로 적용
- 상환권, 동반매도권, 누적 배당은 계산하지 않음

## 3. 내일 할 일 — 출시 체크리스트 (약 1시간)

0. **저장소 공개 여부 결정** (5분): `vcwoong-ai/vcwoong`은 현재 **public**이다. 정식판 빌드 파일(`dist/release/`)은
   `.gitignore`로 제외했지만, 소스가 공개라 누구나 `build.mjs`로 정식판을 만들 수 있다.
   판매 전 저장소를 private으로 바꾸거나 `products/equityplan`을 별도 private 저장소로 옮길 것을 권장한다.
   (체험판도 브라우저에서 도는 코드라 개발자 도구로 잠금을 풀 수는 있다. 이 가격대에서는 감수하는 위험이다.)

1. **체험판 직접 써보기** (10분): `dist/site/demo.html`을 더블클릭. 실제 계약 1건을 넣어 숫자가 맞는지 확인.
2. **결제 상품 만들기** (20분) — 둘 중 하나:
   - **Gumroad** 또는 **Lemon Squeezy**(해외 MoR, 세금·결제·파일 전달 자동): 상품 2개 생성
     (개인 ₩49,000 / 팀 ₩190,000), 각각 `dist/release/EquityPlan.html` 업로드.
   - **크몽**(국내, 수수료 높지만 자체 유입 있음): "디지털 상품/템플릿"으로 등록. 해외 플랫폼과 병행 추천.
3. **`config.json` 수정** (5분): `buyUrl`, `teamBuyUrl`, `supportEmail`, `siteUrl`, `business`(사업자 정보).
   - 국내에서 유료 판매하면 **사업자등록 + 통신판매업 신고**가 필요하다. 이미 DealMind 사업자가 있으면 그대로 쓴다.
   - 현직 심사역 등 사실인 경력이 있으면 `makerLine`에 한 줄 넣는다 (예: "현직 VC 심사역이 설계"). 전환율에 크다.
4. **빌드** (1분): `node products/equityplan/build.mjs`
5. **랜딩 배포** (10분): Vercel에서 새 프로젝트 → 이 저장소 → Root Directory를 `products/equityplan/dist/site`,
   Framework는 Other, Build Command 비움. 또는 `dist/site` 폴더를 Netlify Drop에 끌어다 놓기.
   **`dist/release`는 절대 배포 폴더에 넣지 않는다.**
6. **구매 테스트** (5분): 본인 카드로 1건 결제 → 파일 수신 → 실행 → 환불.

## 4. 유입 채널 (매출을 결정하는 부분)

- **검색**: "지분 희석 계산기", "RCPS 리픽싱 계산", "SAFE 조건부지분인수 전환 계산", "청산우선권 계산"
  — 랜딩·체험판 제목과 설명에 이미 반영. 구글 서치 콘솔·네이버 서치어드바이저에 사이트 등록.
- **커뮤니티 1회 게시**: 디스콰이엇, 스타트업 오픈채팅, 링크드인(본인 계정), 페이스북 스타트업 그룹 —
  "텀시트 받았을 때 참가적 우선주가 내 몫을 얼마나 줄이는지 계산해 보는 무료 도구" 형태로 체험판 링크.
- **액셀러레이터·창업보육센터**: 팀 라이선스(포트폴리오사 배포 허용)를 교육 교안으로 제안. 한 곳이 개인판 수십 건 값.
- **DealMind 교차 판매**: DealMind 랜딩/뉴스레터에서 무료 체험판 링크 → 창업자·VC 리드 확보.

## 5. 유지보수

- 계산 엔진: `src/engine.js` (의존성 없음). 테스트: `node --test products/equityplan/test/engine.test.cjs` (12건)
- UI: `src/app.js`, `src/app.css`, `src/app.html` / 랜딩: `src/landing.html` / 예시 데이터: `src/example.js`
- 수정 후 `node products/equityplan/build.mjs` → 결제 플랫폼에 새 `EquityPlan.html` 업로드
  (Gumroad·Lemon Squeezy는 기존 구매자에게 업데이트 파일이 자동 제공됨 — 랜딩의 "1년 업데이트" 약속은 이것으로 지킨다)
- 복제 방지는 없다. 파일 공유를 완전히 막을 수 없는 대신, 서버·라이선스 서버 운영 부담을 없앴다.
